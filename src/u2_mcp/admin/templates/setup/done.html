VS Code

Add this to .vscode/mcp.json in a project, or to your user MCP configuration:

{
  "servers": {
    "u2": {
      "type": "http",
      "url": "{{ public_url }}/"
    }
  }
}

Nobody can use this connection from an AI assistant until it has a grant. After you finish, open the connection and add one under Access. Admins need a grant too: being an admin gives no data access. Each person then creates a personal access token on My access, which also shows the configuration for their MCP client.
